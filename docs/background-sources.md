# Fontes da biblioteca ampliada

330 desenhos vetoriais adaptados de Pattern Monster, sob licença MIT.

- Repositório: https://github.com/catchspider2002/svelte-svg-patterns
- Revisão fixada: `803e30bfde106cf094581aabfc80ced2062c5ab7`
- Dados: `src/routes/_index.js`
- Licença integral: `public/creative-library/LICENSE-PatternMonster.txt`
- Adaptações: cores, espessura, escala, nomes em português e renderização independente em SVG. Somente os paths foram importados; nenhum código do site é executado.

12 composições vetoriais adicionais são originais do Click & Gruda. Cada desenho possui 15 paletas: 5.130 opções novas, além dos 105 fundos anteriores (5.235 no total). As opções de cor são variações do mesmo desenho, não desenhos diferentes.

Os vetores externos são servidos localmente e carregados sob demanda. Nenhuma imagem remota ou API é necessária para aplicar os fundos; projetos exportados embutem o SVG e o aviso MIT.
